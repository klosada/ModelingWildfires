I built interactive geospatial dashboards that run a spatial model of wildfire spread across real landscapes, mapping satellite and environmental data. The first reconstructs a California wildfire from real data with validation against its observed burn perimeter, and the second is a sandbox for testing how each input shapes fire spread.

The project was originally developed as a grid-based cellular-automata model for a graduate Modeling & Simulation course, then independently expanded into this dual-dashboard web app. Source code and model details are available on GitHub.

Wildfire model and data processing in Python · Data extraction in Google Earth Engine · Web app in JavaScript with Mapbox GL JS

California Study Area

Reconstructs the Rabbit Fire that ignited on July 14, 2023 in Riverside County, California, using real environmental data.

  • Cell-level data: Dynamic World land cover, Landsat 9 NDVI, and SRTM elevation with its derived slope were exported from Google Earth Engine and also used as basemaps.
  • Uniform across all cells: Wind speed and direction from the fire day were pulled from Open-Meteo historical weather data.
